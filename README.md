# Fıstık360

Fıstık360, kuruyemiş sektörüne özel bir dikey pazaryeri MVP'sidir.

## Özellikler

- Public marketplace ana sayfası
- Toptan ürün listesi ve detay sayfaları
- Mahalle bazlı mağaza keşfi
- Mağaza vitrini ve paket görünümü
- Supabase schema hazırlığı

## Başlangıç

```bash
npm install
npm run dev
```

## Ortam değişkenleri

```bash
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

## Yapı

- Next.js + TypeScript + Tailwind
- Supabase schema: supabase/schema.sql
- Vercel deploy için hazır başlangıç yapısı
